# 数据格式说明

四份数据放在 `miniprogram/data/` 下。首次启动会写入本地存储，之后以本地存储为准
（改源码后需要清空小程序存储或走「设置 → 恢复示例数据」才会重新导入）。

> 想直接从教务系统的 Excel / Word 课表导入，请看 [文件导入说明.md](文件导入说明.md)。

---

## 1. 我的课表 `courses.js`

```js
{
  id: 'c01',                                    // 唯一 id，导入时重复会覆盖
  name: '高等数学(上)',                          // 课程名
  teacher: '张建国',                             // 任课教师（可空）
  roomId: 'A301',                               // 教室编号，必须与 classrooms.js 的 id 对应
  day: 1,                                       // 星期，1=周一 … 7=周日
  start: 1,                                     // 起始节次（含）
  end: 2,                                       // 结束节次（含）；单节课时 start === end
  weeks: { start: 1, end: 16, parity: 'all' },  // 周次规则
  color: '#2b5cff',                             // 课程块颜色（可空，会自动分配）
  note: '带教材与习题册',                        // 备注（可空）
}
```

### 周次 `weeks` 的三种写法

| 写法 | 含义 |
|---|---|
| `{ start: 1, end: 16, parity: 'all' }` | 第 1-16 周每周 |
| `{ start: 1, end: 16, parity: 'odd' }` | 第 1-16 周的单周 |
| `{ start: 1, end: 16, parity: 'even' }` | 第 1-16 周的双周 |
| `{ start: 1, end: 16, parity: 'custom', list: [1,3,5,7] }` | 明确列出（导入时用得少） |
| `'1-16周'` / `'1-16单'` / `'1-16双'` | 字符串写法，解析时会自动转换 |
| `[1,3,5,7]` | 数组写法，自动转成 custom |

### 导入文本格式

```
# 以 # 开头是注释
课程名,星期,起始节,结束节,教室,周次
高等数学(上),周一,1,2,A301,1-16
大学物理,周四,3,4,A201,1-16单
```

宽松写法（空格 / Tab 分隔，周次可省略，省略时默认 1-16 周）：

```
程序设计基础 周三 5-6 A301 1-16周
大学物理 周四 3-4 A201
```

星期可写 `周一` / `星期一` / `一` / `1`；节次可写 `1-2` / `1~2` / `1到2` / `3`。

## 2. 教室字典 `classrooms.js`

**空教室查询的全集**——没登记在这里的教室不会出现在结果中。

```js
{
  id: 'A301',                 // 唯一编号，必须与课表 roomId 一致（建议大写）
  name: 'A301',               // 显示名，可以是"图书馆201自习室"这样的长名
  building: '综合楼A座',       // 楼栋，用于分组筛选
  campus: '主校区',            // 校区（多校区时使用）
  floor: 3,                   // 楼层
  capacity: 180,              // 座位数
  type: 'multimedia',         // normal | multimedia | lab | language | drawing
  openForStudy: true,         // 是否允许学生自习（false 的教室默认不显示）
  facilities: ['projector', 'ac', 'socket'],  // projector | ac | socket | accessible
}
```

> 课表里出现但字典里没有的 `roomId`，页面会给出「教室未登记」提示，
> 并且这些教室**不会**出现在空教室结果里。

## 3. 全校教室占用表 `occupancy.js`

结构与课表相同，但不需要 `teacher` / `color` / `note`：

```js
{ id: 'o301', name: '大学语文', roomId: 'A101', day: 1, start: 1, end: 2,
  weeks: { start: 1, end: 16, parity: 'all' } }
```

**这是空教室准确性的关键数据**。获取途径：

1. 教务系统导出的全校课表（含教室、周次、节次）→ 提取这几个字段
2. 学校公开的教室借用 / 排课公示
3. 手动录入已知的长期占用

导入方式：「设置 → 数据管理」目前支持 JSON 备份的导入导出；
批量导入入口在未来版本会开放给占用表，当前可先改 `data/occupancy.js`。

## 4. 节次时间表 `periods.js`

```js
{ period: 1, start: '08:00', end: '08:45', section: 'morning' }
```

- `period` 节次序号（必须唯一、递增）
- `start` / `end` 该节的上课起止时刻（24 小时制 `HH:mm`）
- `section` 仅用于界面分组：`morning` / `afternoon` / `evening`

节次数量可增可减（比如有的学校一天 12 节、有的只有 8 节），
课表网格、节次选择器都会自动适配。

## 5. 配置项 `config/index.js`

| 配置 | 说明 |
|---|---|
| `TERM.startDate` | **第 1 周的周一**，周次计算的基准，填错会全盘错位 |
| `TERM.totalWeeks` | 学期总周数 |
| `REMIND.aheadMinutes` | 主提醒：课前多少分钟提醒（默认 20） |
| `REMIND.finalAheadMinutes` | 最后提醒（默认 5） |
| `REMIND.autoPopupMinutes` | 打开小程序时距上课小于该值才弹层（默认 30） |
| `NOTIFY_CHANNEL.*` | 震动 / 提示音 / 弹层 / 日历 的默认开关（用户可在设置页覆盖） |
| `SERVER.baseUrl` | 留空则纯本地运行 |
| `SERVER.subscribeTemplateId` | 订阅消息模板 ID |
| `COLORS` | 课程块配色池 |
