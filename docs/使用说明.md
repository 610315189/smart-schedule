# 使用说明（学生版）

> 目标：3 分钟把手里的课表变成"能提醒你、还能帮你找自习位"的小工具。

---

## 第一步：打开小程序

微信开发者工具 → 导入项目 → 选择 `wechat-smart-schedule` 目录 → 编译。
第一次打开会加载一份**示例课表**，界面、倒计时、空教室查询都能立刻看到效果。

---

## 第二步：换成自己的课表

### 方式 A：选 Excel / Word 文件导入（最省事）

1. 先把教务系统导出的课表文件（`.xlsx` 或 `.docx`）发到微信的**「文件传输助手」**
2. 底部「课表」→ 顶部切到「批量导入」→ 点 **「选择文件（从微信聊天记录）」**
3. 选中刚才那个文件，小程序会**自己找到课表在哪**并显示预览：

   ```
   ✓ 识别出 6 门课程（布局：课表网格）
   🔍 识别到表头（第 5 行，占 2 行）
      字段完整度：100%
   星期一 1-2节 · A301 · 张建国 · 1-16周
   星期三 1-2节 · B301 · 刘伟 · 1-16周
   ```

4. 核对无误后点「确认导入」→ 选「追加」或「替换」

> **不用管文件长什么样**：标题、学号、打印时间、空行、备注都会被自动跳过；
> 表格里有合并单元格也没关系；表头写法随意（"科目""教学地点"都能认）；
> 甚至**没有表头**、列顺序被打乱，也能靠列里的内容特征推断出来。
>
> 标了橙色「需确认 80%」的条目是没识别出某个字段的，导入后可以手工改。
> 详细规则见 [文件导入说明.md](文件导入说明.md)。

### 方式 B：粘贴文字

1. 把课表整理成下面这样，一行一门课：

   ```
   高等数学(上),周一,1,2,A301,1-16
   大学英语,周一,3,4,A401,1-16
   程序设计基础,周三,5,6,A301,1-16
   大学物理,周四,3,4,A201,1-16单
   ```

   > 字段顺序：**课程名,星期,起始节,结束节,教室,周次**
   > 周次写 `1-16` 表示每周；`1-16单` 表示单周；`1-16双` 表示双周。
   > 也可以只用空格分隔，周次可省略（默认 1-16 周）。

2. 切到「批量导入」→ 粘贴到「粘贴文本导入」框 → 点「解析」→ 核对预览 → 点「确认导入」

### 方式 C：一门一门加

「课表」→ 右下角 **+** → 填名称、星期、起止节次、教室、周次、颜色 → 保存。

---

## 第三步：核对开学日期（很重要）

「设置 → 学期设置」里：

- **开学第一周周一**：填**第 1 周的周一**。填错的话，周次、单双周、空教室全都会算错。
- **学期总周数**：一般 16~20 周。

示例数据用的是 `2026-09-07`。

---

## 第四步：配置提醒

「设置 → 上课提醒」：

| 项 | 建议值 | 说明 |
|---|---|---|
| 提前提醒 | 20 分钟 | 从宿舍走到教室一般要这么久 |
| 最后提醒 | 5 分钟 | 临门一脚的催促，会标红 + 长震动 |
| 自动弹窗范围 | 30 分钟 | 打开小程序时，小于这个时长才弹提醒 |
| 震动 / 提示音 / 弹窗 | 都开 | 按喜好关掉 |

改完点 **「测试一次提醒效果」** 可以立刻看到真实效果。

---

## 第五步：让"不打开也能被提醒"生效（关键一步）

小程序自身不能后台常驻，所以请务必做这一步：

**「设置 → 手机系统日历 → 同步整学期」**

它会把本学期所有课程（示例数据约 178 条）写进你手机的系统日历，
每节课提前 20 分钟响铃。**即使你一个月不打开小程序，系统也会提醒你。**

- 只在**手机真机**上有效，开发者工具会提示失败，属正常现象
- 提示需要授权时点「允许」
- 点一次就够了，**重复点会重复添加**日历条目
- 换学期或改了课表后，可以「只同步本周」做小范围更新

---

## 第六步：找空教室自习

底部「空教室」标签页：

1. **选日期**：今天 / 明天 / 后天，或点日历图标挑日期
2. **选时段**：上方两个选择器选起止节次，或用快捷按钮
   - `现在` —— 自动定位到当前（或下一节）
   - `上午 / 下午 / 晚上`
   - `连空 2 节 / 连空 3 节` —— 只找能连续空这么久的教室
3. **筛选**（可选）：教学楼、座位数、有插座、有空调、仅可自习教室
4. **看结果**：每间教室会显示
   - `第5-6节 空` —— 你要的这段时间是空的
   - `可连用 第1-10节（7小时30分）` —— 这间教室今天能坐多久
   - `今日空堂 3 段：...` —— 全天没课的时间段
5. **点教室** —— 看当天完整的空堂与占用明细，还能一键复制教室名

### 另一个入口

在「课表」页点任意**空白格子**，直接弹出"这个时段有哪些空教室"。

### ⚠️ 关于准确性

如果只看得到自己的课表，结果会**偏多**——别的班级占用同一间教室你是看不到的。
页面顶部会有橙色提示。想准确的话，需要导入全校教室占用表，
详见 [空教室原理与准确性.md](空教室原理与准确性.md)。

## 每天怎么用（推荐动线）

| 时间 | 操作 | 得到什么 |
|---|---|---|
| 早上起床 | 打开小程序 | 弹出"今天有 N 节课"总览 |
| 出门前 | 自动提醒（20 分钟） | 震动 + 弹层告诉你哪间教室 |
| 上课前 5 分钟 | 自动提醒（最后提醒） | 标红催促，避免迟到 |
| 课间 / 空堂 | 点底部「空教室」 | 找一间能坐的空教室 |
| 期末换学期 | 设置里改开学日期 + 重新同步日历 | 一切归位 |

---

## 数据安全

- 所有数据默认**只存在你手机本地**（`wx.setStorageSync`）
- 除非你主动点「上传课表」，否则不会发往任何服务器
- 换手机不会自动迁移，建议用「设置 → 数据管理 → 导出备份」把 JSON 存一份

---

## 遇到问题

| 现象 | 原因 / 解决 |
|---|---|
| 收不到提醒弹层 | 检查「页面弹窗提醒」开关；或点「测试一次提醒效果」 |
| 日历同步失败 | 只能在真机用；授权被拒后去「··· → 设置 → 授权管理」重新允许 |
| 空教室结果过多 | 尚未导入全校占用表，见上文说明 |
| 周次显示不对 | 「开学第一周周一」填错了 |
| 课表里出现"教室未登记" | 教室编号不在 `data/classrooms.js` 里，补一条即可，否则它不会出现在空教室结果中 |
| 节次时间不对 | 改 `data/periods.js` 里每个节次的 `start` / `end` |
