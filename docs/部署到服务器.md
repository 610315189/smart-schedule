# 部署到服务器（让公网可访问）

网页版是**纯静态文件**：只有 HTML / CSS / JS / 图片，没有后端、没有数据库、不需要 Node 运行环境。
所以"上传服务器"本质就是：**把 `web/` 目录里的文件放进服务器的网站根目录**。

---

## 一、部署产物

已经打好包：**`web-deploy.zip`**（13 个文件，90 KB）

解压后的结构（直接就是网站根目录内容）：

```
index.html          ← 入口
manifest.json       ← PWA 清单
sw.js               ← 离线缓存
404.html            ← 404 页
css/app.css
js/wx-shim.js  js/bundle.js  js/ics.js  js/ui.js  js/app.js
icons/icon-192.png  icon-512.png  icon-maskable-512.png
```

> 另有一种最省事的方式：只上传 **`web/standalone.html`**（265 KB，CSS/JS/图标全内联）。
> 重命名为 `index.html` 放到网站根目录即可，一个文件搞定。

---

## 二、方案 A：宝塔面板（最常见，图形化操作）

适合：阿里云 / 腾讯云 / 华为云 等云服务器，已装宝塔面板。

1. 宝塔 → **网站** → 添加站点
   - 域名：填你的域名（没有域名就填服务器公网 IP）
   - PHP 版本：**纯静态**（不需要 PHP）
2. 进入站点目录（一般是 `/www/wwwroot/你的域名`）
3. 删除默认的 `index.html`、`404.html` 等
4. 点 **上传** → 选择 `web-deploy.zip` → 上传后右键 **解压** 到当前目录
5. 浏览器访问 `http://你的域名` 或 `http://服务器公网IP`

**开启 HTTPS（很重要，PWA 和通知需要）**：
宝塔 → 站点设置 → **SSL** → Let's Encrypt → 申请免费证书 → 开启"强制 HTTPS"。

**配置 404（可选）**：
站点设置 → 配置文件，在 `location / {` 里加：

```nginx
error_page 404 /404.html;
```

## 三、方案 B：SSH 命令行 + Nginx

适合：有服务器 SSH 权限、习惯命令行。

```bash
# 1) 本地：把部署包传到服务器（Windows PowerShell 也有 scp）
scp web-deploy.zip root@你的服务器IP:/tmp/

# 2) 登录服务器
ssh root@你的服务器IP

# 3) 解压到网站目录
mkdir -p /var/www/schedule
cd /var/www/schedule
unzip -o /tmp/web-deploy.zip

# 4) 写 Nginx 配置
cat > /etc/nginx/sites-available/schedule <<'EOF'
server {
    listen 80;
    server_name 你的域名或IP;

    root /var/www/schedule;
    index index.html;

    # Service Worker 不要缓存，保证更新能生效
    location = /sw.js {
        add_header Cache-Control "no-cache";
    }

    # 静态资源长缓存（文件名带 ?v= 会自然失效）
    location ~* \.(css|js|png|svg|ico)$ {
        expires 7d;
        add_header Cache-Control "public";
    }

    location / {
        try_files $uri $uri/ /index.html;
    }

    error_page 404 /404.html;
}
EOF

# 5) 启用并重载
ln -sf /etc/nginx/sites-available/schedule /etc/nginx/sites-enabled/
nginx -t && systemctl reload nginx
```

**配 HTTPS**（推荐，用 certbot 免费证书）：

```bash
apt install -y certbot python3-certbot-nginx
certbot --nginx -d 你的域名
```

> ⚠️ 没有域名的服务器（只有 IP）申请不了 Let's Encrypt 证书。
> 想用 IP 直接访问：`http://服务器IP` 即可，但 PWA（添加到主屏幕、离线）不会生效。

## 四、方案 C：免费静态托管（没有服务器也能用）

网页版是纯静态，以下平台都**免费**且自动配 HTTPS：

### 1. Cloudflare Pages（推荐，国内访问相对稳）

1. 注册 <https://dash.cloudflare.com>
2. **Workers & Pages → Create → Pages → Upload assets**
3. 把 `web-deploy.zip` 解压后的文件整个拖进去
4. 部署完成得到一个 `xxx.pages.dev` 的网址

### 2. Vercel

1. 注册 <https://vercel.com>
2. **Add New → Project → Upload**（或连 GitHub 仓库）
3. 把解压后的目录拖进去，Framework 选 **Other**
4. 得到 `xxx.vercel.app`

### 3. Netlify

1. 注册 <https://app.netlify.com/drop>
2. 直接把解压后的文件夹拖到页面上
3. 立即得到网址

### 4. Gitee Pages（国内，需要实名认证）

如果已经推到 Gitee 仓库：

1. 仓库 → **服务 → Gitee Pages**
2. 部署分支选 `master`，**部署目录填 `web`**
3. 需要先完成实名认证；免费版每次更新后要手动点一次"更新"

得到 `https://lu-mingbo.gitee.io/smart-schedule` 之类的地址。

> 注意：Gitee Pages 的部署目录只能是仓库里的子目录，我们正好是 `web/`。

## 五、方案 D：单文件版（最省事）

如果只是想让同学能用：

1. 把 `web/standalone.html` 重命名为 `index.html`
2. 传到任何能放网页的地方（服务器、网盘直链、甚至路由器的文件服务）
3. 一个文件就是一个完整应用

也可以直接把这个 HTML 文件**发微信给同学**，对方用浏览器打开即可（`file://` 下也能用，
只是 Service Worker 不生效）。

## 六、部署后要做的事

### 1. 重新生成二维码

局域网二维码里的地址是 `192.168.x.x`，换成公网后要重新生成：

```bash
node tools/make-qrcode.js --url https://你的域名/
```

也可以直接访问网页 → **设置 → 分享给同学**，页面会自动显示当前访问地址的二维码。

### 2. 验证访问

- 首页能打开，倒计时正常走动
- 底部四个 tab 都能切换（记住之前修过"能看不能点"的 CSS 问题，部署的是修复后版本）
- 手机上用 HTTPS 打开后，可"添加到主屏幕"，之后离线也能用

### 3. 两个容易踩的坑

| 现象 | 原因 | 解决 |
|---|---|---|
| 页面空白、控制台报 404 | 文件没放在根目录，或解压到了子目录 | 确认 `index.html` 直接位于网站根目录 |
| 更新代码后页面还是旧的 | Service Worker 缓存 | 浏览器强制刷新，或在 `sw.js` 里把 `CACHE = 'smart-schedule-v1'` 改成 v2 |
| `?v=2` 那串数字没用上 | 部署的 `index.html` 是旧版 | 重新解压 `web-deploy.zip` |

## 七、要不要后端？

**不需要。** 网页版完全在浏览器里跑：

- 课表数据存在手机浏览器的 localStorage
- Excel/Word 解析在浏览器里完成（纯 JS 实现的 ZIP/DEFLATE 解压）
- 提醒靠浏览器通知 + `.ics` 日历导出

`server/` 目录里的 Node 后端是当初给**微信小程序订阅消息**用的，网页版用不到，
部署时可以忽略。
