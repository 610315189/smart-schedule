# 智能课表小程序（WeChat Mini Program）

一个原生微信小程序：**上课时间提醒防迟到误课** + **空教室查询用于自习**。

数据默认全部存在手机本地，离线可用；可选部署一个零依赖 Node 后端开启微信服务通知推送。

---

## 一、它解决什么问题

| 痛点 | 本项目的做法 |
|---|---|
| 记错上课时间 / 快到点了才发现 | 首页秒级倒计时 + 课前 20 分钟 / 临门 5 分钟两级提醒（震动 + 提示音 + 醒目标红弹层） |
| 不打开小程序就完全收不到提醒 | 一键把**整学期课程写进手机系统日历**，系统级闹钟，离线也响 |
| 想看又懒得开小程序 | 可选后端定时任务推送**微信订阅消息**（需自行申请模板并部署） |
| 想去自习却不知道哪间教室空着 | 「空教室」页按日期 + 节次反查空闲教室，支持楼栋 / 座位数 / 设施筛选，还会告诉你这间教室今天能连用多久 |
| 一天里哪几节没课心里没数 | 首页「今日空堂」自动算出没课的时间段 |
| 课表在教务系统里，懒得一条条敲 | **选 Excel / Word 文件导入，程序自己找课表**：跳过标题与说明、判断布局、对齐每一列；没有表头也能靠列内容推断 |

## 二、快速开始

### 1. 用微信开发者工具打开

1. 打开 **微信开发者工具** → 导入项目
2. 目录选择本仓库根目录 `wechat-smart-schedule/`
3. AppID 选择 **测试号**（`project.config.json` 里已填 `touristappid`），或换成你自己的 AppID
4. 编译运行即可 —— 已内置示例课表，无需任何配置就能看到完整效果

> 项目是**原生小程序**，没有引入 npm 依赖，不需要构建步骤。

### 2. 换成你自己的课表

四种方式，任选：

- **Excel / Word 文件导入**（最省事）：「课表 → 批量导入 → 选择文件（从微信聊天记录）」，
  选中教务系统导出的 `.xlsx` 或 `.docx`，小程序会**自己找到课表在哪**并给出预览，确认后写入。
  识别能力包括：

  | 场景 | 处理方式 |
  |---|---|
  | 表格前面有标题、学号、打印时间、说明 | 自动跳过，从真正的表头行开始 |
  | 表头写法五花八门 | 模糊匹配：`科目`→课程名、`教学地点`→教室、`授课教师`→教师 |
  | 表头分两行（大类 + 细分） | 合并两行做复合表头 |
  | **完全没有表头** | 按每列的内容特征推断（全是"周一~周五"的列就是星期列，以此类推） |
  | 列顺序被打乱 | 同样按内容特征对齐，不依赖列的先后 |
  | 同一张表里还有别的表格 | 自动切成数据块，挑最像课表的那一块 |
  | 合并单元格、连堂 | 跨行合并的课自动合成一门 1-2 节的课，不会重复 |

  支持两种课表布局：

  | 布局 | 长什么样 |
  |---|---|
  | 列表式 | 表头是「课程名称 / 星期 / 节次 / 教室 / 周次」，每行一门课 |
  | 网格式 | 上方一行是「星期一…星期日」，左侧是节次，格子内写着课程名、教师、教室、周次 |

  单元格里的「高等数学(上) / 张建国 / A301 / 1-16周」这类多行文本会被拆成对应字段。
  详见 [docs/文件导入说明.md](docs/文件导入说明.md)。

- **粘贴文本**：「课表 → 批量导入 → 粘贴文本导入」，粘进下面这种文本，点「解析 → 确认导入」
  ```
  高等数学(上),周一,1,2,A301,1-16
  程序设计基础,周三,5,6,A301,1-16
  大学物理 周四 7-8节 A201 1-16周单
  ```
- **逐条添加**：「课表 → 右下角 +」
- **改源码**：编辑 `miniprogram/data/courses.js`，清掉本地存储后重启

### 3. 必须做的一步：核对开学日期

「设置 → 学期设置 → 开学第一周周一」填**第 1 周的周一**。
填错会导致周次、单双周判断全错。示例数据用的是 `2026-09-07`。

### 4. 让提醒真正生效（重要）

打开小程序时的提醒只在「你正在用小程序的这一刻」有效。要做到「不打开也能被提醒」，请去
**设置 → 同步到手机日历 → 同步整学期**（约 180 条，需 1 分钟左右）。
该功能**只在手机真机有效**，开发者工具会提示失败，属正常现象。

## 四、功能细节

### 4.1 防迟到 / 防误课：三道保险

| 保险 | 生效条件 | 实现位置 |
|---|---|---|
| ① 打开小程序即提醒 | 打开小程序的瞬间 + 停留期间每 15 秒检查 | `utils/notify.js` + 首页每秒倒计时 |
| ② 手机系统日历 | **不用打开小程序**，系统按时响铃 | `utils/calendar.js` |
| ③ 微信订阅消息 | 后端定时扫描并推送服务通知 | `server/src/reminder.js` |

两级提醒（可在设置页调）：

- **主提醒**：默认课前 **20 分钟** —— "还有 20 分钟上课，该出发了"
- **最后提醒**：默认课前 **5 分钟** —— 标红 + 长震动 + "马上要上课了，请立即出发"

同一节课同一天不会重复弹窗（`ss_reminded` 里做去重记录，自动清理 3 天前的旧记录）。

补充：**每天第一次打开小程序**会弹一次"今天上什么课"的总览（有课前提醒时让位给提醒）。

### 4.2 空教室查询（自习）

- 按 **日期 + 起止节次** 查询，快捷入口：现在 / 上午 / 下午 / 晚上 / 连空 2 节 / 连空 3 节
- 筛选：教学楼、座位数、是否允许自习、设施（插座 / 空调 / 投影）、排序（楼栋 / 座位 / 空闲时长）
- 每间教室显示：**查询时段是否为空**、**今天能连用到第几节**、今日各段空堂、当天被哪些课占用
- 在「周课表」里点击任意**空白格**，直接看那个时段的空教室

教室占用来自两个数据源合并计算：

1. 你的课表（只能看到自己班的占用）
2. 全校占用表 `data/occupancy.js`（**可选，但决定准确性**）

> ⚠️ 只导入自己的课表时，结果会**偏多**——别的班级占用同一间教室你看不到。
> 页面顶部会明确提示这一点。详见 [docs/空教室原理与准确性.md](docs/空教室原理与准确性.md)。

### 4.3 课表管理

- 周网格视图：7 天 × 10 节，课程块按颜色区分，显示"当前时间红线"
- 只看周一~周五 / 回本周 / 上一周 / 下一周 / 周次选择器
- 自动**冲突检测**（同天 + 节次重叠 + 周次有交集）
- 支持单双周（`1-16周(单)`）、区间周次、任意起止节次
- 课程备注字段（"带实验报告""需自带电脑"），首页会显示

## 五、后端（可选）：微信服务通知

如果希望"小程序没打开也能收到微信通知"，部署 `server/`：

```bash
cd server
cp .env.example .env      # 填入 WX_APPID / WX_SECRET / WX_TEMPLATE_ID
node src/index.js         # 零依赖，Node 16+ 直接跑
```

本地调试图省事可以 `DEV_MODE=true node src/index.js`，此时不校验微信 code、推送只打日志。

然后把服务地址填进 `miniprogram/config/index.js`：

```js
const SERVER = {
  baseUrl: 'https://你的域名',
  subscribeTemplateId: '你的模板ID',
};
```

详见 [server/README.md](server/README.md)。

> **注意**：微信订阅消息是"授权一次发一条"的机制。用户每次打开小程序都会重新授权，
> 因此实际能推几条取决于用户打开小程序的频率。若追求"绝对不漏"，请以**手机系统日历**为主。

## 七、常见问题

**Q：提醒弹层一直不出现？**
A：检查「设置」里「页面弹窗提醒」是否开启；以及是否已到提醒范围（默认 30 分钟内）。
可点「测试一次提醒效果」立刻验证。

**Q：同步日历失败 / 提示不支持？**
A：`wx.addPhoneCalendar` 只在手机真机可用，开发者工具必然失败。另外首次调用会弹授权框，
拒绝后需要到「右上角 ··· → 设置 → 授权管理」里重新允许。

**Q：空教室结果太多、明显不准？**
A：说明还没导入全校占用表，当前只是"我没有课的教室"。见第五节说明。

**Q：怎么改上课时间（节次作息）？**
A：编辑 `miniprogram/data/periods.js`，改每个节次的 `start` / `end`。
改完需要在「设置 → 数据管理 → 导出备份」前先清缓存，或直接用导出/导入覆盖。

**Q：想加自己的教室（比如宿舍楼自习室）？**
A：编辑 `miniprogram/data/classrooms.js`，按同样字段加一条，`openForStudy: true` 即可。

**Q：微信开发者工具里 import 报 "touristappid" 相关错误？**
A：`project.config.json` 里把 `appid` 换成你自己的小程序 AppID 即可；测试号也能跑全部本地功能。

**Q：Excel 导入提示"这是旧版 .xls 格式"？**
A：`.xls` / `.doc` 是 1997 年的二进制格式（OLE2 复合文档），不是 ZIP，端上无法解析。
用 Excel 或 WPS 打开后「另存为」`.xlsx` / `.docx` 再导入即可。

**Q：Excel 导入后课程名/教室识别不准？**
A：先确认教室字典里有这间教室——**字典匹配是最可靠的识别方式**。
导入预览里标了「需确认」的条目就是没识别出教室或周次的，导入后可在「课程列表」里逐条改。
若表头不是常规写法，可参考 [docs/文件导入说明.md](docs/文件导入说明.md) 调整。

**Q：导入的课程名是乱码？**
A：多半是 CSV 用了 GBK 编码。小程序只能按 UTF-8 解码，
请在 Excel/WPS 里另存为「CSV UTF-8」。`.xlsx` / `.docx` 内部固定是 UTF-8，不会乱码。

**Q：在小程序里怎么把文件发给自己？**
A：`wx.chooseMessageFile` 只能从**微信聊天记录**里选文件。
把课表文件先发到「文件传输助手」，再在小程序里选择即可。

## 八、技术说明

- **零依赖**：小程序端不使用任何 npm 包，后端只用 Node 内置模块（`http` / `https` / `fs`），不存在装不上依赖的问题
- **数据落点**：小程序 `wx.setStorageSync`（换手机不迁移）；后端 `server/data/db.json`
- **算法一致性**：`server/src/schedule.js` 与 `miniprogram/utils/schedule.js` 规则一致，
  并由 `tools/test-server.js` 交叉验证两端对同一时刻的判断结果完全相同
- **时区**：后端统一按 `TZ_OFFSET_HOURS`（默认 UTC+8）计算墙上时间，不依赖服务器时区
